Placer ici un fichier nommé exactement :

    ipsa_logo.png

Le logo doit être un fichier PNG (fond transparent recommandé).
Il sera affiché à gauche du bandeau bleu en haut de la fenêtre,
dans un PictureBox de 50×50 px en mode Zoom.

Si le fichier est absent, le bandeau s'affiche sans logo
(aucune erreur n'est générée).
